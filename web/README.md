# SolGeo Change Evidence web reader

This is a static Next.js reader for the Python-generated case bundle.

```powershell
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

The website does not process satellite data. Build or publish a case bundle
from the repository root first. Read [`../docs/LEARNING-PATH.md`](../docs/LEARNING-PATH.md)
to learn the interface progressively.
