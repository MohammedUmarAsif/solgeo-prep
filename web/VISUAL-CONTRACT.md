# SolGeo web visual contract

The interface is a research portfolio, not a generic analytics dashboard.

- Visual direction: editorial field notes, cold-neutral paper, satellite cyan,
  dark evidence panels, and compact mono labels.
- Dials: variance 7, motion 5, density 5.
- Typography: large measured headlines, readable body copy, mono metadata.
- Layout: asymmetric editorial hero, split evidence workspace, restrained cards,
  and visible section numbering.
- Motion: small hover lifts and a direct slider; reduced-motion users get no
  essential motion.
- Scientific rule: real imagery carries source/date/QA labels; synthetic
  previews carry a claim gate and never masquerade as geography.
- Interaction rule: every control has a plain-language reason. Every metric
  has a unit or an explicit screening-signal label.
- Accessibility: keyboard slider, semantic headings, visible focus, readable
  contrast, responsive layout, and text equivalents for maps.
- Forbidden: purple AI gradients, decorative maps without provenance, fake
  accuracy figures, and long opaque components.
