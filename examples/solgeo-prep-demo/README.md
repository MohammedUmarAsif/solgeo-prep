# SolGeo Prep demo artifact

This folder contains the deterministic synthetic output generated by:

```powershell
uv run solgeo-prep demo --output-dir outputs/solgeo-prep-demo --size 64
```

The files demonstrate the Project 1 output contract: a quality table, evidence
JSON, a checksum-backed manifest, and georeferenced GeoTIFF layers. The raster
values are synthetic and must not be interpreted as observations of Dubai or
any other location.
